# 미르테 (Myrte)

모임 강의 시연용으로 만든 **가상의** 스킨케어·향 브랜드 정적 사이트입니다. 실존 브랜드가 아니며, 장바구니와 뉴스레터는 동작만 흉내 낼 뿐 결제나 메일 발송은 하지 않습니다.

시각 언어는 [Builders Lounge 브랜드 룩북](https://lounge.ai-hub-os.com/#lookbook/aesop)의 이솝(Aesop) 톤 — 웜 베이지 배경, 앰버 `#A6773B`, 세리프 워드마크와 넉넉한 여백 — 을 참고했습니다. 이솝의 이름·로고·제품명은 사용하지 않았습니다.

## 페이지

- [메인](https://aihubos.github.io/myrte/) — 히어로, 브랜드 이야기, 추천 제품, 공간, 뉴스레터
- [제품 목록](https://aihubos.github.io/myrte/products.html) — 스킨·바디·향·헤어 필터
